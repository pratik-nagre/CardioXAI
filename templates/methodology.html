01

Framingham Heart Study Dataset

The study uses the publicly available Framingham Heart Study (FHS) Longitudinal Cohort dataset (frmgham2.csv), a landmark epidemiological study tracking cardiovascular events in adults from Framingham, Massachusetts. Only PERIOD = 1 (baseline examination) observations are used to prevent temporal data leakage.

The primary outcome variable is ANYCHD (any coronary heart disease event), with TIMECHD converted to years as the survival duration. The sex variable is remapped from {1,2} → {0,1} for compatibility with binary cross-entropy objectives.

Cohort

~4,434 patients at baseline (PERIOD=1) after filtering zero-duration survival records. 80/20 stratified train-test split on ANYCHD.

Outcome

Binary: ANYCHD (any CHD event). Survival duration: TIMECHD / 365.25 (years). 10-year event-free probability is the primary risk metric.

02

Data Pipeline

Rigorous preprocessing is critical to avoid data leakage. The pipeline enforces a strict train-first paradigm: imputation statistics and the StandardScaler are fit only on the training set, then applied to both sets.

PERIOD=1 filter → SEX remap → Train/Test Stratified Split (80/20) →
Median imputation (continuous) → Mode imputation (binary/categorical) →
One-hot encode 'educ' → StandardScaler (fit on train) → Save scaler/imputer to models/

The imputation impact is logged per-feature (mean shift %, variance shift %) to validate that imputation does not materially distort the feature distributions. A RANDID overlap assertion prevents any patient from appearing in both train and test splits.

03

Ensemble Risk Models

The risk estimation layer combines a survival model with three probabilistic classifiers, forming an ensemble that provides both interpretable hazard scores and robust event probability estimates.

Cox Proportional Hazards (CoxPH)

Fitted via lifelines.CoxPHFitter. Provides interpretable log-hazard coefficients (β) and Kaplan-Meier-style survival functions. Primary source of XAI contributions.

XGBoost Classifier

Gradient-boosted decision trees trained on ANYCHD. Predicts P(event) via predict_proba. Captures non-linear interaction effects between features.

LightGBM Classifier

Leaf-wise boosted classifier. More efficient on large tabular datasets. Provides complementary risk probability estimate to XGBoost.

Random Forest Classifier

Bagged ensemble of decision trees. Provides high-variance reduction through averaging. Ensemble vote threshold is set at P > 0.15.

h(t | x) = h₀(t) · exp(β₁x₁ + β₂x₂ + ... + βₙxₙ) # Cox Hazard

Ensemble Risk Vote = Σ 𝟏[P_model(x) > 0.15] for model ∈ {XGB, LGB, RF}
04

Variational Autoencoder (VAE)

The VAE is the backbone of the counterfactual generation process. It is trained to learn a smooth, low-dimensional latent manifold that represents the distribution of physiologically plausible patients. Counterfactuals are searched within this latent space, ensuring all generated interventions are realistic.

05

Counterfactual Optimizer

Given a patient's encoded latent vector z₀, the optimizer performs gradient-based search to find a modified latent vector z* that, when decoded, produces a patient profile with significantly reduced CHD risk while respecting clinical constraints.

z* = argmin_z [ L_risk(decode(z)) + λ₁ · ||z - z₀||² + λ₂ · L_constraint(decode(z)) ]

# L_risk: Combined ensemble risk loss
L_risk = α · log_hazard(cox) + (1-α) · mean(proba(tree_models))

# Constraint enforcement (projected gradient)
x_cf[IMMUTABLE] ← x_orig[IMMUTABLE] # hard freeze
x_cf[AGE] ← max(x_cf[AGE], x_orig[AGE]) # directional

The optimizer uses Adam with a scheduled learning rate. At each step, the decoded counterfactual is projected back onto the feasibility manifold by replacing immutable features with their original values and clipping directional features.

06

Explainability (XAI)

Explainability is delivered through Cox coefficient feature contributions. For each patient, the log-partial-hazard contribution of each feature is computed as the product of the fitted Cox coefficient and the patient's scaled feature value:

contribution_i = β_i · x_i # for feature i

# Positive → increases hazard (increases risk)
# Negative → decreases hazard (protective)

This provides an additive, linear decomposition of the log-hazard score, directly interpretable by clinicians without requiring post-hoc approximation methods (e.g., SHAP). Contributions are sorted by absolute magnitude and visualized as a diverging bar chart, separately showing risk-increasing and protective factors.

07

Feasibility Constraints

A key differentiator of this system is the three-class constraint taxonomy that ensures counterfactuals are medically realistic and ethically sound:

🔒 Immutable

Features that cannot change under any intervention: biological sex, prior cardiovascular events (CHD, MI, Stroke, Angina), education level. These are hard-locked to original values.

↑ Directional

Features that can only change in one direction. Age can only increase over time; interventions cannot roll back biological age. Enforced via max() clipping.

✓ Actionable

Features freely modifiable: blood pressure, cholesterol, BMI, glucose, smoking status, medications. These are the targets for clinical prescription generation.

📊 Recourse Tiers

Strong: >20% relative risk reduction. Partial: 5–20% reduction. None: <5% achievable reduction within constraints.
